# Next Steps

This repository is a starting scaffold. Complete the challenge in this order:

1. Install/verify Docker, kubectl, Kind, Git, and Python.
2. Build the backend image locally.
3. Run the Flask application locally.
4. Create the Kind cluster.
5. Push the image to Docker Hub.
6. Deploy PostgreSQL and backend to Kind.
7. Verify `/` and `/health`.
8. Configure a GitHub Actions self-hosted runner on the same machine.
9. Add Docker Hub secrets to GitHub.
10. Push to `main` and verify the CI/CD deployment.
11. Demonstrate readiness/liveness behavior.
12. Perform the intentional database hostname failure.
13. Debug it using Kubernetes commands and logs.
14. Fix the configuration and verify recovery.
15. Record the 8–12 minute video.
